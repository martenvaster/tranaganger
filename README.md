# Hästmatte – Serieponnyerna (version 3)

Den här versionen ersätter de gamla geometriska hästarna med tre nya handillustrationsliknande serieponnyer. Övriga funktioner från version 2 finns kvar.

## Prova
Öppna `index.html` i en webbläsare. Mappen `assets` måste ligga bredvid `index.html`.

## Uppdatera GitHub Pages
Ladda upp **både `index.html` och mappen `assets` med de tre PNG-filerna** till huvudnivån i GitHub-repot `tranaganger`. Skriv över gamla `index.html`. Behåll namn och filstruktur. GitHub Pages uppdateras efter en kort stund.

## Sparade framsteg
Appen använder samma lokala sparnyckel som version 2 (`hastmatte-v2`). Sparade stjärnor och utmärkelser behålls när du uppdaterar samma webbadress.
